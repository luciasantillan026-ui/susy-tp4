Sistema de Gestión de Inventario y Stock – Supermercado Susy

Descripción del proyecto
Este proyecto tiene como finalidad desarrollar un sistema de gestión de inventario y control de stock para el Supermercado Susy, un comercio de barrio ubicado en Avellaneda.
El sistema permitirá registrar productos, consultar las cantidades disponibles, controlar las entradas y salidas de mercadería y generar alertas cuando los productos alcancen el nivel mínimo de stock establecido.

Objetivo
Mejorar la organización y el control de la mercadería mediante una herramienta que permita mantener actualizada la información del inventario y facilitar la toma de decisiones relacionadas con la reposición de productos.

Funcionalidades principales
- Registro y consulta de productos.
- Registro de entradas, salidas y ajustes de stock.
- Actualización de las cantidades disponibles.
- Control de stock mínimo y generación de alertas de reposición.
