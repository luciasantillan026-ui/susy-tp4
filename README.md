Sistema de Gestión de Inventario y Stock – Supermercado Susy

Descripción del proyecto
Este proyecto tiene como finalidad desarrollar un sistema de gestión de inventario y control de stock para el Supermercado Susy, un comercio de barrio ubicado en Avellaneda.
El sistema permitirá registrar productos, consultar las cantidades disponibles, controlar las entradas y salidas de mercadería y generar alertas cuando los productos alcancen el nivel mínimo de stock establecido.

Objetivo
Mejorar la organización y el control de la mercadería mediante una herramienta que permita mantener actualizada la información del inventario y facilitar la toma de decisiones relacionadas con la reposición de productos.

Herramientas utilizadas
- Git y GitHub: para el control de versiones, la organización del repositorio y el trabajo colaborativo.
- GitHub Projects: para gestionar las historias de usuario y organizar las tareas mediante un tablero Kanban.
- BPMN: para representar gráficamente el proceso de reposición de stock.
- IA: como apoyo para organizar y revisar la documentación.

Funcionalidades principales
- Registro y consulta de productos.
- Registro de entradas, salidas y ajustes de stock.
- Actualización de las cantidades disponibles.
- Control de stock mínimo y generación de alertas de reposición.

## Indicadores de control y estándares de desempeño
Para evaluar el funcionamiento y el rendimiento del Sistema de Gestión de Inventario y Stock del Supermercado Susy, se establecen indicadores de control y estándares de desempeño que permitirán verificar el cumplimiento de los objetivos del sistema.

| Indicador | ¿Qué controla? | Estándar esperado |
|---|---|---|
| Tiempo de consulta de stock | Cuánto tarda el sistema en mostrar el stock de un producto. | Máximo 5 segundos. |
| Tiempo de actualización de stock | Cuánto tarda en reflejarse una entrada o salida de mercadería. | Máximo 5 segundos. |
| Capacidad de almacenamiento | Cantidad de productos que puede gestionar el sistema. | Hasta 10.000 productos. |
| Tiempo de desarrollo e implementación | Plazo estimado para desarrollar e implementar el sistema. | Máximo 3 meses. |

Estos indicadores permitirán evaluar el rendimiento del sistema, detectar posibles inconvenientes y comprobar que responda adecuadamente a las necesidades del supermercado.

## Declaración de Uso de Inteligencia Artificial

Durante el desarrollo de este proyecto se utilizaron herramientas de Inteligencia Artificial, principalmente ChatGPT y Claude, como recursos de consulta y apoyo para distintas etapas del trabajo.
Estas herramientas se utilizaron para comprender y organizar los contenidos, mejorar la redacción de la documentación, planificar las actividades en GitHub Projects, elaborar las historias de usuario y representar el proceso de reposición de stock mediante BPMN.
A continuación, se presentan algunos ejemplos de las consultas realizadas:

- **Documentación:** se solicitó ayuda para organizar la información y describir las funcionalidades principales del Sistema de Gestión de Inventario y Stock del Supermercado Susy.
- **Proceso BPMN:** se consultó cómo representar el proceso de reposición de mercadería, identificando los participantes, las actividades y las decisiones que intervienen.
- **Historias de usuario:** se solicitó orientación para redactar historias de usuario relacionadas con el descuento automático del stock, las alertas de stock mínimo y el registro de ingreso de mercadería.
- **GitHub Projects:** se consultó cómo organizar las tareas del proyecto y clasificarlas en los estados Por Hacer, En Progreso y Listo.

Las respuestas obtenidas no fueron incorporadas directamente sin revisión. Se realizaron modificaciones para adaptarlas al funcionamiento del Supermercado Susy y a los requisitos del proyecto. Por ejemplo, se ajustaron las actividades y los participantes del proceso BPMN, se revisó el contenido de las historias de usuario y se organizaron las tareas de acuerdo con las etapas previstas para el desarrollo del sistema.
También se revisó la documentación para mantener la coherencia entre los objetivos, las funcionalidades, el proceso modelado y la planificación del proyecto.
La utilización de estas herramientas tuvo como finalidad facilitar la comprensión y elaboración de los contenidos.
